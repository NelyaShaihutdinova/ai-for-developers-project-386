# ADR-0002: Структура главной страницы

**Status:** accepted

## Context

Нужно определить содержимое и структуру главной страницы (`/`) сервиса «Запись на звонок».

## Decision

Главная страница состоит из:
- **Шапка (header):** имя/бренд владельца, без навигации и CTA
- **Hero:** «Запись на звонок к <Имя владельца>»
- **Блок «Как записаться»:** текстовый список из трёх шагов, без иконок/таймлайна
- **CTA:** одна кнопка «Выбрать тип встречи», ведущая на `/meetings`
- **Футер:** «© 2026 Запись на звонок»

Ссылка на интерфейс владельца на главной НЕ показывается.

## Consequences

- Минимальный дизайн, быстрая реализация MVP
- Один путь конверсии: гость → hero → как записаться → CTA → каталог
- Имя владельца создаёт персонификацию, но берётся из конфигурации
