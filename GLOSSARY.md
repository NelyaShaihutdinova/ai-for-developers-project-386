# Glossary

## Запись на звонок

Название сервиса (бренд). Используется в футере и системных текстах.

## Каталог типов встреч (Meeting Type Catalog)

Отдельная страница `/meetings`, на которой гость видит доступные типы встреч и выбирает один для записи.

## Интерфейс владельца (Owner Interface)

Отдельный будущий интерфейс для владельца календаря. Позволяет создавать типы встреч и просматривать список всех предстоящих бронирований. Доступен по известному URL без авторизации. На главной странице гостя НЕ отображается. В scope проекта.

## Владелец календаря (Calendar Owner)

Единственный пользователь сервиса, который задаёт типы встреч и просматривает список всех бронирований. Задан заранее через конфигурацию, не требует авторизации.
